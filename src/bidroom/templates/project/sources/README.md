# Sources

Put the authoritative source material for this pursuit here.

Suggested files:

- `rfp.md` — the solicitation or opportunity document.
- `capabilities.md` — the bidder's evidence, references, capacity, and commercial position.
- `policy.md` — the human-readable policy that `policy.json` implements.

The engine reads the structured decision record, not these Markdown files. The agents read the files through the Switch rooms.
